# DateDeck
A Decky Loader plugin that shows the date next to the clock in the Steam Deck header.

## Options
- Position: can be left or right of the time
- Order: month/day or day/month
- Abbreviate or number the month
- Zero-pad numbers
- Show year
- Year format (2 or 4 digits)

## Building
```
npm install
npm run build
```
